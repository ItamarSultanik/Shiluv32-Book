# חוברת מאמרים שילוב לב
הרפו הזה משמש לעבודה על חוברת המאמרים של שילוב לב בישיבת מעלה גלבוע. מאמרים שנכתבו על ידי תלמידי השילוב בזמן חורף של שנת תשפ"ו 2026.
אני, העורך, איתמר סולטניק, העלתי את הדברים לפה כדי שאני אוכל לעבוד על החוברת מכמה מכשירים שונים בנוחות - ולגיבוי למקרי חירום.
בדיעבד, החלטתי לפתוח את הרפו כציבורית, על מנת שהמאמרים יהיו נגישים אונליין בצורה פתוחה, ותופץ תורת תלמידי הישיבה.
הרבה מהמאמרים פה נהדרים וחשובים, חלקם אף מכילים חידושים משמעותיים בתחומם.
חלק מהמארים די גרועים. לא נורא - תמיד יש כאלה.
